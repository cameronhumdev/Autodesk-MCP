# Module: `subscriber`

Skeleton for one isolated subscriber stack.

## Inputs

| Name | Description |
|------|-------------|
| `subscriber_id` | Unique id (e.g. `acme`) |
| `public_ai` | Expose shared/public route |

## Outputs

| Name | Description |
|------|-------------|
| `namespace` | K8s namespace name |
| `ingress_host` | Hostname for the AI UI |
